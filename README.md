# 📊 Netflix Data Analytics Dashboard

## 📌 Project Overview

This project is a **Netflix Data Analytics Dashboard** developed using Python to explore and visualize Netflix Movies and TV Shows.

The dashboard analyzes the Netflix dataset to discover useful insights about content distribution, genres, ratings, countries, and release trends.

## 🎯 Objectives

- Analyze Netflix Movies and TV Shows
- Understand content distribution by type
- Identify the most common genres
- Analyze ratings and content categories
- Explore content availability across countries
- Study release trends over the years
- Present insights through clear visualizations

## 🛠️ Technologies Used

- 🐍 Python
- 🐼 Pandas
- 📊 Matplotlib
- 📈 Seaborn
- 📓 Jupyter Notebook

## 📂 Dataset

The project uses the **Netflix Movies and TV Shows dataset**, containing information such as:

- Title
- Type
- Director
- Cast
- Country
- Release Year
- Rating
- Duration
- Genres
- Date Added

## 🔍 Key Analysis

The dashboard provides visualizations for:

1. Movies vs TV Shows
2. Content distribution by country
3. Top genres on Netflix
4. Rating distribution
5. Content added over time
6. Release year trends
7. Top countries producing Netflix content
